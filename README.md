# Мемори для Мии и Василисы

Локальная детская браузерная игра по требованиям из `TECHNICAL_SPEC_MEMORY_GAME.md`. Сервер, аккаунт и подключение к интернету не нужны: игровой код, 50 иллюстраций и кириллический шрифт находятся в проекте.

## Запуск

Нужен Node.js 18 или новее. У проекта нет сторонних npm-зависимостей.

```bash
npm run dev
```

Откройте `http://127.0.0.1:5173`. Открывать `index.html` через `file://` не рекомендуется: ограничения ES-модулей отличаются между браузерами.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Готовая статическая сборка создаётся в `dist/`. Её можно разместить на любом статическом веб-сервере. После копирования файлов внешние CDN и backend не используются.

## Структура данных

- `src/data/letters.js` — 28 разрешённых букв и четыре слога.
- `src/data/emojis.js` — 50 эмодзи со стабильными ID и русскими названиями.
- `src/data/words.js` — 50 слов длиной 3–5 букв.
- `src/data/illustrations.js` — метаданные 50 локальных изображений.
- `src/data/config.js` — игроки, категории и размеры полей.

Чтобы добавить или заменить элемент, обновите соответствующий массив. У каждого элемента должен оставаться уникальный стабильный `id`. Новое изображение положите в `assets/images/` и укажите локальный путь в `illustrations.js`.

## Сохранение

Игра использует один ключ `memoryGameData` в `localStorage`. Профили, звёзды, история, знакомые элементы и настройка звука сохраняются автоматически.

Для полного ручного сброса откройте консоль разработчика и выполните:

```js
localStorage.removeItem('memoryGameData');
location.reload();
```

Кнопки сброса в детском интерфейсе нет.

## Локальные материалы

- Иллюстрации сгенерированы специально для этого проекта с помощью OpenAI ImageGen, затем разделены и оптимизированы в WebP. Исходные листы сохранены в `assets/source/`.
- Шрифт Neucha распространяется по SIL Open Font License; текст лицензии находится в `assets/fonts/OFL-Neucha.txt`.
- Четыре мягких звуковых события синтезируются локально через Web Audio API и не обращаются к сети.
